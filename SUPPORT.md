# Support

## How to get help

If you're having trouble with Vault Controller, there are several ways to get help:

### GitHub Issues

The [GitHub Issue tracker](https://github.com/example/vault-controller/issues) is the best place to report bugs or request new features.

### General Questions

For general questions, please use the [GitHub Discussions](https://github.com/example/vault-controller/discussions) if enabled, or check the documentation in the `docs/` folder.
